# Rachel — Portfolio

A minimalist, responsive portfolio starter built with plain HTML, CSS and JavaScript.

## Customize
1. Open `index.html`.
2. Replace `hello@example.com` with your real email.
3. Replace the Behance / LinkedIn / Instagram `href="#"` links.
4. Replace each `.placeholder` block with your project images.
5. Update project titles, categories and descriptions.

## Free publishing
You can publish this folder on Netlify, GitHub Pages, or another static hosting provider. No build step is required.

## Project filtering
The Work section includes filters for:
All, Chinese, Western, Websites, Apps, Branding and Banners.
